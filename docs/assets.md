# Gestão de Assets - Quiz dos Professores

## Convenção de Nomes
- **Professores:** `professor_[id]_[estado].png` (Estados: normal, feliz, bravo).
- **Salas:** `sala_[id].png`.

## Especificações
- **Estilo:** Pixel Art.
- **Placeholder:** Atualmente utiliza o ícone do Godot com `hframes = 3` para simular a troca de estados.

## Estrutura de Frases
As frases dos balões de fala são definidas em `scripts/Jogo.gd` e podem ser expandidas para serem carregadas via JSON ou API por cadeira.
